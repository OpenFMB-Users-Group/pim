# OpenFMB PIM HTML

This repository contains the OpenFMB Platform Independent Model (PIM) documentation in HTML format.

## How to Open the HTML Documentation

To view the documentation properly, follow these steps:

### Step 1: Extract and Open
1. Unzip the documentation files to your local drive
2. Right-click on `index.htm`
3. Select "Open with Microsoft Edge"

### Step 2: Enable IE Mode
1. Click the "..." (three dots) at the top right corner of Microsoft Edge
2. Select "Reload in IE mode"
3. Allow blocked content when prompted

### Troubleshooting: If "Reload in IE mode" is not available

If you don't see the "Reload in IE mode" option, you need to enable it first:

1. **Open Settings**
   - Click the "..." (three dots) menu
   - Click "Settings"

2. **Navigate to Default Browser**
   - In the left menu, find and click "Default Browser"

3. **Enable IE Mode**
   - Look for "Allow sites to be reloaded in Internet Explorer mode"
   - Enable this option

After enabling IE mode, return to the documentation page and follow Step 2 above.

## Available Versions

The documentation includes multiple versions:
- v2.0.0
- v2.1.0  
- v2.2.0

Navigate to the specific version folder to access that version's documentation.

## Note

The documentation requires Internet Explorer compatibility mode to display correctly due to the Enterprise Architect generated HTML format.
