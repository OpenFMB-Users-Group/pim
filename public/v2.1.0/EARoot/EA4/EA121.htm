The value of a control command which could either be a setpoint or a control schedule in curve.<br/><br/>The attribute modBlk is used to tag out a device. if it is TRUE, any setpoints and control schedule in a message payload should be ignored. <br/><br/>It should also be presented in a status profile.<br/><br/>Any modBlk value change (i.e. TRUE to FALSE and vice versa) should trigger an event.<br/><br/>
